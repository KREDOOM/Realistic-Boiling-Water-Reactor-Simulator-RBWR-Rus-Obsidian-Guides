# Roblox RBWR — русские гайды для Obsidian

Русскоязычные заметки, чек-листы и справочники по **Realistic Boiling Water Reactor Simulator (RBWR)** в Roblox. Хранилище включает руководства по Unit 1 и отдельным системам Unit 2, скриншоты игровых панелей и PDF для сверки.

**Начать чтение:** [Главная — навигация по гайдам](Главная.md).

**Дальнейшая работа:** [План доработки](План%20доработки.md).

> Материалы относятся только к игре Roblox RBWR и не являются инструкциями для эксплуатации реальных энергетических установок. Соответствие технических рекомендаций текущей версии игры пока не подтверждено.

## Как открыть в Obsidian

1. Скачайте и распакуйте репозиторий целиком или клонируйте его через Git. Отдельного Markdown-файла недостаточно для отображения всех вложений.
2. В Obsidian выберите **«Открыть папку как хранилище» / Open folder as vault**.
3. Укажите корневую папку репозитория — ту, в которой находятся `README.md`, `.obsidian`, `_PDF` и `_resourses`.
4. Откройте заметку **«Главная»**. При желании закрепите её вкладку для быстрого возвращения к оглавлению.

Для чтения заметок, переходов по внутренним ссылкам, просмотра скриншотов и PDF дополнительные плагины не нужны. В репозитории уже есть настройки и сторонние плагины в `.obsidian`; включайте их только при необходимости и после проверки доверия к ним.

## Как читать и дополнять гайды

- Не смешивайте процедуры **Unit 1** и **Unit 2**: перед использованием проверяйте, к какому блоку относится заметка.
- Различайте показание на конкретном скриншоте, рекомендуемую уставку и порог срабатывания защиты. Это не взаимозаменяемые значения.
- Перед изменением чисел или порядка действий сверяйтесь с PDF и текущей версией игры. Указывайте источник, страницу и версию, если она известна.
- Непроверенные сведения помечайте явно; наличие PDF в хранилище само по себе не означает, что заметка уже сверена с ним.
- При переименовании заметок, разделов и вложений обновляйте связанные ссылки. Папки с изображениями и PDF не следует отделять от хранилища.
